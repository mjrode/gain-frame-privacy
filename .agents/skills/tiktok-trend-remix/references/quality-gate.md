# TikTok Trend Remix Quality Gate

Run this gate after trend selection and again on contact sheets.

## 1. Comprehension gate

For each concept, answer in one plain sentence:

> The viewer sees [setup], swipes because [tension], and gets [payoff].

Reject it when any condition is true:

- the explanation needs the source trend to make sense;
- the first two slides do not form a clear setup/payoff or useful sequence;
- the metaphor is doing more work than the product truth;
- the app appears without resolving the viewer's question;
- the hook promises something the remaining slides do not deliver.

## 2. Source-fidelity gate

Classify the source's actual visual grammar:

- `raw UGC`: camera-roll photos, native TikTok text, little or no layout;
- `native screenshot`: phone screenshots, notes, chats, maps, or app surfaces;
- `designed utility`: intentionally designed guide, checklist, diagram, or card;
- `meme/remix`: recognizable cultural image plus short punchline;
- `cinematic`: deliberately shot imagery where photography carries the story.

The adaptation must stay in the same production-signal band unless research
shows the format recurring in another band. Raw UGC must not be upgraded into a
poster campaign, custom illustration system, pseudo-editorial magazine, arcade
UI, or object metaphor.

## 3. Current-product gate

Before using any GainFrame UI:

1. Verify the current shipping version through the official App Store/iTunes
   record.
2. Record the version and release date.
3. Compare the source asset's known version with the shipping version.
4. Use only a current captured screen or current official listing asset.
5. If neither exists, request a current capture instead of substituting an old
   screenshot or redrawing the UI.

## 4. Contact-sheet rejection tests

Reject and remake the carousel when:

- it looks like an ad before it looks like a TikTok photo post;
- three consecutive slides use the same composition without the source format
  requiring repetition;
- decorative typography competes with the message;
- a screenshot is too small to read on a phone;
- removing the visual metaphor makes the idea clearer;
- the final product frame feels pasted on rather than earned by the story.
