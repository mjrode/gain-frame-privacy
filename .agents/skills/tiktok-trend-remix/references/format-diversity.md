# TikTok Batch Format Diversity

Use this gate when producing three or more posts. Select mechanisms before
topics. A new audience, app lineup, or headline does not create a new format.

## Format families

| Family | Typical sequence | Useful GainFrame payoff |
|---|---|---|
| Receipt reveal | provocative setup -> visual evidence -> interpretation | real comparison or dashboard |
| Transformation timeline | starting state -> setbacks -> checkpoints -> measured change | progress photos and change over time |
| Misconception flip | common belief -> contradiction -> explanation -> practical rule | body-composition education |
| Identity or POV story | specific person -> recognizable moments -> self-recognition -> next step | habit or tracking insight |
| Visual diagnostic | image or silhouette -> viewer guesses -> annotated reveal -> takeaway | explain what a metric can and cannot show |
| Challenge or self-test | prompt -> viewer choice/guess -> delayed answer -> action | compare perception with tracked evidence |
| Decision tree | goal question -> branching choices -> recommendation | choose a tracking workflow |
| Contrast story | expectation vs reality or input vs output -> side-by-side proof | lifts/scale versus visible physique change |
| Meme escalation | repeated visual premise -> escalating labels -> brand-aware punchline | relatable gym tracking frustration |
| Ranked or roundup list | numbered options -> verdicts -> recap | honest app discovery |
| Interface-native story | chat, notification, calendar, report, or phone surface -> interruption -> proof | make the product feel discovered inside daily life |
| Object-led metaphor | physical prop -> reframing line -> product payoff | turn an abstract progress problem into a tangible object |

These are families, not templates. Preserve the researched source's actual
mechanic instead of forcing every concept into the examples above.

## Five-post gate

Before drafting, create a matrix with one row per post and these columns:

| Post | Family | Hook | Sequence | Payoff | Visual grammar | Semantic promise | CTA | Viewer job |
|---|---|---|---|---|---|---|---|---|

The batch passes only when:

1. At least four families are represented.
2. At least three posts are not rankings, roundups, or numbered lists.
3. App ranking/roundup appears at most once.
4. Every post preserves the researched source's native visual grammar. Raw UGC
   may recur when the sources use it; do not turn it into a new branded art
   direction just to make rows look different.
5. No two rows match on three or more of Hook, Sequence, Payoff, Semantic
   promise, CTA, and Viewer job.
6. No cover formula or reveal position repeats.
7. Every post has a distinct primary viewer job until the available jobs are
   exhausted.

Reject and replace concepts until all seven checks pass. Record the final matrix
in the research handoff and the fingerprint in each post's `trend-brief.md`.

## Anti-patterns

- Five ranked app lists for different audiences.
- Five numbered advice lists with different nouns.
- Reusing "I ranked five, but #3..." more than once.
- Reusing the same screenshot-card layout with different copy.
- Calling a palette, title, or audience change a new format.
- Choosing only the easiest deterministic renderer after research found more
  suitable mechanics.
- Routing every concept through an existing GainFrame TikTok art direction.
- Treating a real app screenshot as permission to reuse the surrounding old
  social template.
- Inventing a poster, metaphor, prop, or branded design system when the source
  is a raw photo post.
