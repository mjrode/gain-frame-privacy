# The Photos You Almost Deleted — Prompt Pack

## Direction

- Audience: lifters who cannot see slow change
- Visual family: after-hours training zine, hard flash, deep charcoal, bone-white type, restrained GainFrame red
- Protagonist: anonymous cropped athlete; never imply a real customer or a guaranteed result
- References: `docs/assets/tiktok/motivate/re-enter-your-prime/` for style; real GainFrame UI only on slide 6
