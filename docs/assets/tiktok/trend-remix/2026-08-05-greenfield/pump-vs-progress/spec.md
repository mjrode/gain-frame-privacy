# Pump vs Progress

- Format: 4-slide paired-widget choice game.
- Visual system: original late-90s arcade character-select UI; glossy plastic
  cards, pixel sparks, violet/cyan palette, compressed display type.
- Signature metaphor: choose-your-player cards.
- Nearest internal post: `stop-chasing-pump`; shared noun only. The competitive
  choice mechanic, two-character framing, arcade visuals, sequence, and CTA are new.
