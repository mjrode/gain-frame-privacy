## Governance rules (bind every new page)

1. **One page per query intent.** Before writing, run the duplicate check (blog-post-generator Phase 0) AND find this map's cluster — if the query belongs to an existing page, improve that page instead.
2. **Intent before format.** 💰 pages get roundup/vs/alternatives format; 📊 pages get reference/question/quiz format and are judged on impressions + AI citations, not clicks.
3. **Every new post links into its cluster** (3+ contextual links in, 5 related links out) and gets linked FROM the cluster hub within the same commit (anti-orphaning — this site has slow crawl discovery).
4. **Measurement windows are sacred:** no metadata iteration within 7–10 days of a change; check git log before trusting GSC deltas.
5. **Position reliability:** ≥30 impressions before treating a GSC position as real.
6. **Visualizer renders** are the differentiating asset for Cluster 2 — always disclosed as standardized AI renders, always linked to the tool.
7. **YMYL clusters (8)** always hedge, always defer to clinicians, never promise outcomes.
