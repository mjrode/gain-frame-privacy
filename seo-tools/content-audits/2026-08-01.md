### IndexNow has been broken since at least 2026-04-30

Submitting this run's 45 changed URLs returned **`403 UserForbiddedToAccessSite`**. Root cause:
IndexNow verifies ownership by fetching a key file from the site root, and
`https://gainframe.app/99929eeb331db70cd363352a87102acf.txt` was returning **404**.

The key file existed only in `docs/` — the legacy Jekyll tree, which is no longer served. It was
never migrated to `web/public/` when the site moved to Next.js. The file content itself was always
correct (32 hex chars, no trailing newline); only its location was wrong.

`scripts/indexnow-log.csv` records the identical 403 on **2026-04-30**, so Bing, Yandex, Seznam
and Naver have received no valid ping in at least three months. The failure was invisible because
the script logs the status and exits 0.

Fixed in `96263a5` by copying the key into `web/public/`. Resubmitted after the deploy confirmed
the key returns 200.

**Google is unaffected** — it does not participate in IndexNow, and its own submissions were never
routed through this path.

### Two detector bugs found and fixed before any content changed

1. **`content-inventory.mjs` counted only `href="/blog/x/"` links.** 189 markdown-relative links
   (`[Title](../x/)`) in older posts were invisible, so 10 linked posts were reported as orphans.
   Fixed to count all three link styles. The corrected detector immediately surfaced **3 genuinely
   broken internal links** that had been live on the site:
   - `meet-gainframe-guy` → `../fix-progress-photos/` (no such post) → repointed to `5-tips-better-progress-photos`
   - `resistance-training-guidelines` → `../how-often-take-progress-photos/` → repointed to `how-often-progress-photos`
   - `resistance-training-guidelines` → `../body-recomposition-guide/` → repointed to `bulk-cut-or-recomp`
2. **F3 was a false positive.** `average-bicep-size` vs `average-chest-size` scored 0.74 title
   overlap, but `get_search_by_page_query` shows **zero shared queries** — the bicep page serves
   "14.5 inch biceps", the chest page serves "40 inch chest". They are a series sharing a title
   template, never competitors. **No merge performed.** The detector now flags same-template pairs
   as `likely series, verify in GSC before merging` and the report carries a standing warning that
   title overlap is a candidate signal rather than a verdict.

   Merging on the title-overlap signal alone would have deleted a page earning 7,645 impressions.
